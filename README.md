# Matching Game, _by Jaime Sainz_
Matching Game is a program that allows you to train your cognitive abilities!

## How to install it
Shoot me an email to <jsainz.santamaria@gmail.com> and I'll be happy to send you a zip code with the files you need to install it (a javascript, css, and html files). You need t save it in your computer in the same filee, open the html file in you favorite browser and start palying.

## How to play
Click a card with your mouse to uncover a figure. Uncover a second card and try to find a match. If the card have the same figure, they will stay uncovered and you will make a point. The game ends when you find the eight matches. Try to beat the time of other players and finish in the least moves possible.
